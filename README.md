# Dynamic Form Builder

This project demonstrates a simple vanilla JavaScript widget that allows users to dynamically add and remove different types of input fields (text, number, checkbox, date) to a form.

## Features

- Add new form fields with a selected type.
- Remove individual fields dynamically.
- Basic styling for a clean user interface.

## How to Run

1.  **Clone the repository** (or download the files):
    ```bash
    git clone <repository-url>
    cd dynamic-form-builder
    ```
2.  **Open `index.html`** in your web browser. No server is required.

## Usage

- Select an input type from the dropdown menu.
- Click "Add Field" to append a new input to the form.
- Click the "Remove" button next to any field to delete it.
- The "Submit Form" button is for demonstration; it will show an alert.
